\section{First order formal languages}

Every definition given here might be understood as not strictly mathematical. That meaning, we won't dive too much into detailed mathematical descriptions nor ontological remarks about the things that we define. Collections are to be understood in an intuitive sense, as well as known collections like the natural numbers. Consider the collection of natural numbers given along with its operations $+$, $\cdot$.

\begin{dfn}
	A \textit{first order formal language} $\mcL$ is a collection of symbols, each identified with a type\footnote{As in, this object is of type \com{Natural number}, or of type \com{Logical connective}.}. It can be interpreted as a collection of collections. 
	\begin{enumerate} 
		\item At most an infinite countable\footnote{Each variable can be related one-to-one to a natural number.} amount of variables: $$x_1, x_2, x_3, \ldots$$
		\item Constant symbols: $$c_1, c_2, c_3, \ldots$$
		\item Relation symbols, each of them with an associated range $n_i$, a natural number greater than 0. That should be interpreted as \com{they relate $n_i$ variables/constants}: $$R_1^{n_1}, R_2^{n_2}, R_3^{n_3}, \ldots$$
		\item Function symbols, each of them also with a range $m_i$: $$f_1^{m_1}, f_2^{m_2}, f_3^{m_3}, \ldots$$
		\item Logical connectives: $$\cond, \neg, \lor, \land, \bicond.$$
		\item Quantifiers: $$\forall, \exists.$$
		\item Parenthesis and comma: $$(,),,.$$
	\end{enumerate} 
\end{dfn}

Function symbols with range 0 are to be thought of as constant symbols. In intuition, they don't take any input and just output the same thing always. Syntactically, they never change its written form. We also call a range $n$ function symbol a $n$-ary function symbol, the same holds for relations. We shall use the usual language after doing this remark, i.e. unary for $1$-ary, binary for $2$-ary, etc.

What the \com{first order} part of the definition actually means will be determined later, but for an intuitive idea, it refers to the \com{level} on which the things we talk about reside. For exmaple, to make a statement about natural numbers, we should use the first order language of arithmetic. To declare induction on natural numbers we would need to talk about statements of natural numbers, that is, to use a higher order language, in this case, second order\footnote{But is not strictly necessary, as we may see further into these notes.}.

\begin{dfn}
	For a first order formal language $\mcL$, a \textit{chain} is the juxtaposition of symbols of $\mcL$. More mathematically, a chain is a sequence (finite or infinite) of elements of $\mcL$.
	To state that two chains $\alpha_1, \alpha_2$ are equivalent we use $\equiv$ as $\alpha_1 \equiv \alpha_2$.
\end{dfn}

Examples of chains are $x_1x_2x_3\neg$, $\neg\land x_1 ((((($ and $(x_{43}R^{32}_{111}\land (f^{1}_{990}))\cond)f^{90}_1 R^{2}_1R^{3132}_1 f^{0}_2 \land$. As you may see, these chains are nonsense. Well, to construct any chain we have the liberty of putting any symbol of $\mcL$ after another. So we need rules, so these silly chains are excluded and only the ones which we want to develope more theory with remain.

\begin{dfn}
	Next are given the definitions of \textit{term} and \textit{formula}.
	\begin{enumerate}
		\item Any variable is a term.
		\item Any constant symbol is a term.
		\item If $f^{m_i}_i$ is a function symbol and $t_1, \ldots, t_{m_i}$ are terms, then $f^{m_i}_i(t_1,\ldots,t_{m_i})$ is a term.
		\item For a relation symbol $R_j^{n_j}$ and terms $t_1, \ldots, t_{n_j}$ the chain $R_j^{n_j}(t_1, \ldots, t_{n_j})$ is a formula. Moreover, it is an \textit{atomic formula}.
		\item For a formula $\varphi$, $\neg \varphi$ is a formula.
		\item For formulas $\varphi$ and $\psi$, $\varphi \cond \psi$ is a formula.
		\item For formulas $\varphi$ and $\psi$, $\varphi \land \psi$ is a formula.
		\item For formulas $\varphi$ and $\psi$, $\varphi \lor \psi$ is a formula.
		\item For formulas $\varphi$ and $\psi$, $\varphi \bicond \psi$ is a formula.
		\item For a formula $\varphi$ and a variable $x_l$, $\forall x_l (\varphi)$ is a formula.
		\item For a formula $\varphi$ and a variable $x_l$, $\exists x_l (\varphi)$ is a formula.
		\item These are the only rules for the construction of terms and formulas.
	\end{enumerate}
\end{dfn}

We won't prove unique readability, because we are not defining things in a formal enough way yet, and because there's no unique readability for this way of constructing formulas. So, for formulas $\alpha$, $\beta$ and $\gamma$ we can form ambiguous formulas like $\alpha \cond \beta \cond \gamma$ where we have two possible readings. To avoid this misunderstanding, we place parenthesis where its appropiate.

We interpret as usually. $\forall x$ as \com{for all $x$}, $\exists x$ as \com{an $x$ exists} and so on.

Here are some examples for what this definition can and cannot express. I will omit indexes indicating range, assuming that the reader understands that this doesn't matter because its a justified abuse of notation.

	Then, the following are formulas of this language.

		\item For it to be a formula, ${=}(g(f(x),x), h(x,y))$ should be a formula.
		\item Then both $g(f(x),x)$ and $h(x,y)$ should be terms.
		\item So $f(x), x, y$ should be terms.
		\item Finally, x, y are variables, therefore terms, and so the whole chain is a formula.
	\end{enumerate}

\begin{ejem}
	Let $\mcL_{A}$ be the formal language with constants $0$, function symbols of range 2: $+$, $\cdot$ and $\mathrm{S}$ and the relation symbol $=$. Call this language the formal language of arithmetic. Then, the following formulas are named the Robinson's arithmetic axioms. 
	\begin{enumerate}
		\item $\forall x (\neg \sucf{x} = 0)$
		\item $\forall x (\forall y (\sucf{x} = \sucf{y} \cond x = y))$
		\item $\forall y (y=0 \lor \exists x (\sucf{x} = y))$
		\item $\forall x (x + 0 = x)$
		\item $\forall x (\forall y (x + \sucf{y} = \sucf{x + y}))$
		\item $\forall x (x \cdot 0 = 0)$
		\item $\forall x (x \cdot \sucf{y} = x \cdot y + y)$
	\end{enumerate}

	Remember the \com{first order} part of the definition? If not, go back. If yes, then assume that we now, by some divine power, are allowed to introduce chains of the next kind: $\forall \varphi (\Psi)$. Here, $\varphi$ is any formula and $\Psi$ is \com{second order} formula (the aforementioned chain is also one), that is, it may contain formulas as variables\footnote{Therefore, it quantifies over formulas of the first order language. We can take this further and permit new chains to quantify over second order formulas, creating a third order language, and so on. However, bringing new conflicts.}. Now, if we interpret $\varphi(x)$ as in stating a property (that I soon will define) then the following is the (second order) known principle of induction:
\begin{enumerate}
	\item[$8_2$.] $\forall \varphi ((\varphi(0) \land (\varphi (x) \cond \varphi(\sucf{x}))) \cond \forall x (\varphi(x))) $
\end{enumerate}

If we drop the fancy act we get a schema for any property $\varphi$, still in the first order language.
	\begin{enumerate}
		\item[$8_1$.] $(\varphi(0) \land (\varphi (x) \cond \varphi(\sucf{x}))) \cond \forall x (\varphi(x)) $
	\end{enumerate}
	that then makes of this collection of formulas an infinite one (one formula for each property). So our first order formal language definition can't describe induction without running in either of these problems.
\end{ejem}

\begin{ejem}
	Let $\mcL_{\text{日本語}}$ be the formal language consisting of constant symbols denoted as japanese nouns 猫(cat), 魚(fish), 数学(math), $\suugakumono$ (mathematician), $\ldots$, variables interpreted as \com{events} $e, e_n, \ldots$\footnote{This is called neo-Davidsonian event semantics. See \cite{neodavidsonian} if you are interested.}, unary relation symbols denoted by verbs 食べる(to eat), 見る(to see), 勉強する(to study), なる(to become), $\dearu$ (to be\footnote{This is used to state a fact. But we use it as the \com{to be} verb.}), $\ldots$ and binary relation symbols as grammatical particles が(agent), を(patient), に(target), で(context),$\ldots$. No function symbols. Call this, a deficient attempt to formalize the japanese language.

	Then, the following are formulas of $\mcL_{\text{日本語}}$:
	\begin{enumerate}
		\item $\exists e( \text{食べる}(e) \land \text{が}(\text{猫}, e) \land \text{を}(\text{魚},e))$ 
		\item $\exists e( \miru(e) \land \text{が}(\sakana, e) \land \text{を}(\neko,e))$ 
		\item $\exists e ( \benkyousuru(e) \land \ga(\neko,e) \land \wo(\suugaku, e)) $
	\end{enumerate}
	
	The first one is interpreted as: ``There is an event, to eat is related to the event, the agent of the event is a cat and the patient of the event is a fish". In dictionary japanese, a written form could be the next.

	\begin{enumerate}[label=TL\arabic*.]
		\item 猫が魚を食べる. The cat eats the fish.
		\item 魚が猫を見る. The fish sees the cat.
		\item 猫が数学を勉強する. The cat studies mathematics.
	\end{enumerate}

	Now, if we are considering on trying to make a universal assertion, then we would use the quantifier $\forall$ to express it. Say that we want to express \com{every cat is not a mathematician} in $\mcL_{\text{日本語}}$. We decompose it as \com{For any noun that is cat, cat is not mathematician}, but we find a problem, the quantifier requires a variable, and in this formal language, variables are events. Therefore we would state something for any event, then, \com{for any event that is cat $\ldots$}. Absurd. To solve this in a lazy way, assume that variables can be separated as nouns and events, i.e., there are formulas that express that a variable is a noun and a variable is an event, $\mathrm{No}(x)$ and $\mathrm{Ev}(x)$. Then, we can construct the formula
	
	\begin{enumerate}[label=\alph*.]
		\item $\forall x (\forall e_1 ((\mathrm{No}(x) \land \mathrm{Ev}(e_1) \land \dearu(e_1) \land \ga(x, e_1) \land \text{で}(\neko, e_1)) \cond \neg \exists e_2 (\mathrm{Ev}(e_2) \land \dearu(e_2) \land \ga(x, e_2) \land \text{で}(\suugakumono, e_2))))$
	\end{enumerate}

	that translates to

	\begin{enumerate}[label=TL\alph*.]
		\item どの猫も数学者ではない. No cat is a mathematician.
	\end{enumerate}

	Next, consider the formula

	\begin{enumerate}[label=\roman*.]
		\item $\exists e (\mathrm{Ev}(e) \land \mathrm{No}(x) \land \naru(e) \land \ga(x, e) \land \wo(\sakana, e))$ 
	\end{enumerate}
	
	which translates to any of the following

	\begin{enumerate}[label=TL\roman*.]
		\item 魚になる. I become fish. 
		\item 魚になる. Cat becomes fish.
		\item 魚になる. Become fish.
	\end{enumerate}
	As you can notice, not only absurd sentences can be formulas but also the complexity of our formal language greatly exceeds that of the natural one. This is because of the reliance on context that japanese language commonly uses. Not only this language, but also english, and some others. The usually prescind of important information that needs to be filled up in the formal expression.
\end{ejem}

\begin{ejem} \label{ejem:etcs}
	For categories, we consider arrows or functions as having a domain, codomain and its name. Here we'll try to design a formal language for variables that consists of three things. First, note that the identity, and in general any permutation, can represent a collection $X$. So, for any function $f : A \longrightarrow B$ we can stablish $A = \mathrm{id_A}$ and $B = \mathrm{id_B}$. So here, to only work with the same kind of variable, we write $f : \mathrm{id_A} \longrightarrow \mathrm{id_B}$. Abstractly, for arrows, an object will be determined by an arrow $a$ if we have $\dom{a}=a$ and $\cod{a}=a$. 
	Let $\mcL_{C}$ be the formal language consisting of unary function symbols $\mathrm{dom}$ and $\mathrm{cod}$, a range 3 relation symbol $\circ$ and the $=$ symbol. We shall call this the language of functions. The variables are denoted, for now, with $f,g,h,\ldots$. We put $f = g \circ h \equiv \circ(f,g,h)$.

	Then we have the following definition of category found in \cite{onesortedcategories}:
	\begin{enumerate}
		\item $\forall f (\dom{\dom{f}} = \dom{f} \land \dom{f} = \cod{\dom{f}})$
		\item $\forall f (\cod{\cod{f}} = \cod{f} \land \dom{f} = \dom{\cod{f}})$
		\item $\forall f ( \forall g (\dom{g} = \cod{f} \bicond \exists h (h = g \circ f)))$
		\item $\forall (h \forall f( \forall g(h = g \circ f \cond (\dom{h} = \dom{f} \land \cod{h} = \cod{g}))))$
		\item $\forall f ( f = f \circ \dom{f}) \land f = \cod{f} \circ f$
		\item $\forall f(\forall g(\forall h( \forall k( \forall l( \forall \alpha(\forall \beta((k = g \circ f \land \alpha = h \circ k \land l = h \circ g \land \beta = l \circ f) \cond \alpha = \beta)))))))$ 
	\end{enumerate}

Interpreting these axioms, we can see that $\dom{f}$ and $\cod{f}$ are what we call objects. We shall then define:
	$\obj{f} \equiv \dom{f}=f \land \cod{f}=f$.
	
The following are some \com{categorial axioms for sets} due to \cite{lawverecatset}.
	\begin{enumerate}[label=\alph*.]
		\item $\exists t (\obj{t} \land \forall a (\obj{a} \cond \exists f ( \dom{f} = a \land \cod{f} = t \land \forall g( (\dom{g} = a \land \cod{g} = t) \cond f = g))))$
		\item $\exists i (\obj{i} \land \forall b (\obj{b} \cond \exists f ( \dom{f} = i \land \cod{f} = b \land \forall g( (\dom{g} = i \land \cod{g} = b) \cond f = g))))$
		\item $\forall a ( \forall b ((\obj{a} \land \obj{b}) \cond \exists c (\exists \pi_a (\exists \pi_b(
			\obj{c} \land ((\dom{\pi_a} = c \land \cod{\pi_a}= a) \land (\dom{\pi_b} = c \land \cod{\pi_b} = b) \land
			\forall x (\forall f (\forall g ((\dom{f} = x \land \cod{f} = a \land \dom{g} = x \land \cod{g} = b) \cond \exists h (\dom{h} = x \land \cod{h} = c \land \circ(f,\pi_a,h) \land \circ(g,\pi_b,h) \land \forall k ((\dom{k} = x \land \cod{k} = c \land \circ(f,\pi_a,k) \land \circ(g,\pi_b,k)) \cond h = k)))))
			)
			))))) $
	\end{enumerate}

	Our formation rules and conventions are not enough to avoid constructing such monstruous chains. To simplify this a bit more, we can identify a pattern in all formulas. This pattern should be known to the reader and is usually abbreviated by the chain $\exists !$. For any \com{property} that presents in a formula as $\exists x (\varphi(x) \land \forall y(\varphi(y) \cond x = y))$ we abbreviate by $\exists ! x (\varphi(x))$. Then a more compact and elegant form is obtained by using this shorthand and defining the next chains:

	$\mathrm{prodd}(a,b,\pi_a,\pi_b,c) \equiv \obj{c} \land \dom{\pi_a} = c \land \dom{\pi_b} = c \land \cod{\pi_a} = a \land \cod{\pi_b} = b$

	$\mathrm{prodp}(a,b,\pi_a, \pi_b,c) \equiv \forall x (\forall f (\forall g (( \dom{f} = x \land \dom{g} = x \land \cod{f} = a \land \cod{g} = b)\; \cond \exists ! h( \dom{h} = x \land \cod{h} = c \land f = \pi_a \circ h \land g = \pi_b \circ h) )))$

	\begin{enumerate}[label=\alph*.]
		\item $\exists t (\obj{t} \land \forall a(\obj{a} \land \exists! f (\dom{f} = a \land \cod{f} = t))) $
		\item $\exists i (\obj{i} \land \forall b(\obj{b} \land \exists! f (\dom{f} = i \land \cod{f} = b)))$
		\item $\forall a (\forall b( (\obj{a} \land \obj{b}) \cond \exists c (\exists \pi_a (\exists \pi_b ( \mathrm{prodd}(a,b,\pi_a,\pi_b,c) \land \mathrm{prodp}(a,b,\pi_a,\pi_b,c) ))) ))$
	\end{enumerate}
If you haven't figured out what they are meant to interpret, 1. and 2. refer to terminal and initial objects, that is, objects such that for any morphism or arrow $f$ with codomain $t$ (domain $i$) such arrow is unique. The third one refers to the existence of products along with its universal property.

\end{ejem}

This here, requires more machinery to distinguish between multiple collections of variables. We call this abstract place, from where we take objects to quantify, the \textit{universe of discourse}. A formal language with only one universe of discourse is called a \textit{single-sorted}, \textit{one-sorted} or \textit{unsorted} formal language. A formal language with multiple universes of discourse is called a \textit{many-sorted} formal language. To formalize categories we can use something called \textit{first order logic of dependent sorts} which requires that we talk about types. The time has come. Define the following.
\begin{dfn}
	A \textit{free variable of a formula} $\varphi$ is a variable $x$ not quantified. That is, not in the scope of a quantifier $\forall x$ or $\exists x$. The next definition via recursion is given:
	\begin{enumerate}
		\item If $\varphi$ is an atomic formula, then the free variables of $\varphi$ are all its variables.
		\item If $\varphi \equiv \neg \psi$ then the free variables of $\varphi$ are the free variables of $\psi$.
		\item If $\varphi \equiv \psi_1 \land \psi_2$ then the free variables of $\varphi$ are the free variables of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \lor\psi_2$ then the free variables of $\varphi$ are the free variables of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \cond \psi_2$ then the free variables of $\varphi$ are the free variables of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \bicond \psi_2$ then the free variables of $\varphi$ are the free variables of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \forall x \psi$ then the free variables of $\varphi$ are the free variables of $\psi$ without $x$.
		\item If $\varphi \equiv \exists x \psi$ then the free variables of $\varphi$ are the free variables of $\psi$ without $x$.
	\end{enumerate}
\end{dfn}

\begin{dfn}
	A \textit{bound} variable of a formula $\varphi$ is a quantified variable. Recursively:
	\begin{enumerate}
		\item If $\varphi$ is an atomic formula, it has no bound variables.
		\item If $\varphi \equiv \neg \psi$ then its bound variables are the bound variables of $\psi$.
		\item If $\varphi \equiv \psi_1 \land \psi_2$ then its bound variables are both the bound variables of $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \lor \psi_2$ then its bound variables are both the bound variables of $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \cond \psi_2$ then its bound variables are both the bound variables of $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \bicond \psi_2$ then its bound variables are both the bound variables of $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \forall x \psi$ then its bound variables are the bound variables of $\psi$ along with $x$.
		\item If $\varphi \equiv \exists x \psi$ then its bound variables are the bound variables of $\psi$ along with $x$.
	\end{enumerate}
\end{dfn}

And to be a bit more precise.

\begin{dfn}
	A \textit{subformula} $\psi$ of a formula $\varphi$ is defined inductivelt as:
	\begin{enumerate}
		\item If $\varphi$ is an atomic formula then $\varphi$ is its only subformula.
		\item If $\varphi \equiv \neg \psi$ then its subformulas are $\neg \psi$ and the subformulas of $\psi$.
		\item If $\varphi \equiv \psi_1 \land \psi_2$ then its subformulas are $\varphi$ and the subformulas of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \lor \psi_2$ then its subformulas are $\varphi$ and the subformulas of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \cond \psi_2$ then its subformulas are $\varphi$ and the subformulas of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \psi_1 \bicond \psi_2$ then its subformulas are $\varphi$ and the subformulas of both $\psi_1$ and $\psi_2$.
		\item If $\varphi \equiv \forall x \psi$ then its subformulas are $\varphi$ and the subformulas of $\psi$.
		\item If $\varphi \equiv \exists x \psi$ then its subformulas are $\varphi$ and the subformulas of $\psi$.
	\end{enumerate}
\end{dfn}

You might have noticed by now, but here are the definitions of property and statement.

\begin{dfn}
	A \textit{property of} $x$ is a formula with a free variable $x$. If $\varphi$ has a free variable $x$ then we write $\varphi(x)$. If multiple variables $x_1, \ldots, x_n$ occur free in a formula $\psi$ then we write $\psi(x_1, \ldots, x_n)$ and say that $\psi$ is a property of $x_1, \ldots, x_n$.

	A \textit{statement} is a formula with no free variables.
\end{dfn}

Therefore, every formula given on $\mcL_{LM}, \mcL_{A}$ and $\mcL_{C}$ were statements. This works just fine for what they were meant to represent, axioms. Now, that doesn't quite work for the formula $x + 0 = 0$, which is just saying something about 0 and some $x$, but not about any variable $x$.

This concludes the syntactics of formal languages.

Now, to the semantics. We designed formal languages according to certain things we had in mind. Not only that, certain structures. Statements like $\forall x (\exists y( x + y = 0))$ are accurately describing rings, modules, vector spaces, but they do not describe a property of natural numbers. This, will be our notion of validness. A statement is valid for a structure if it correctly expresses its properties. To formalize this, let us define the following.

\begin{dfn}
	For a formal language $\mcL$, a $\mcL$-\textit{structure} $\mathfrak{A}$ consists of a collection $U$ called a universe along with an interpretation of each type of symbol in $\mcL$. This is:
	\begin{enumerate}
		\item The interpretation assigns an $m$-ary function in $U$ for each function symbol $f^{m}$.
		\item It assigns an $n$-ary relation in $U$ to every relation symbol $R^{n}$.
		\item It assigns an element of $U$ to any constant symbol.
	\end{enumerate}

	When we think of this definition and the universe as classes or sets, we then get a mathematical formalization of what a structure is.
\end{dfn}

The examples shown before are modeled after an structure, so there's a structure for each of them. Let's see this more precisely.

\begin{ejem}
	\begin{enumerate}
		\item For $\mcL_A$, we choose the natural numbers as the universe. The structure $\mathfrak{N}$ is then described as following. We assign $S(n)$ to the function that outputs the succesor of a natural number $n$, described by $n + 1$. For $+$ and $\cdot$ we do the obvious. Same goes for constant $0$. Then, Robinson's axioms, that is, the statements constructed are intuitively true for the structure $\mathfrak{N}$ we have given.

To make this more simple, let us denote the structure $\mathfrak{N}$ as $\mathfrak{N} = \langle \mathbb{N}, n \mapsto n+1, +, \cdot, 0 \rangle$ and the following structures.
		\item For $\mcL_{\text{日本語}}$ we choose the japanese language as $\mathfrak{J} = \langle \mathrm{nouns}, \mathrm{verbs}, \ga, \nijp, \de, \wo \rangle$. Here, the structure is just as modeled. If we try with the english language, then we would use $\mathfrak{E} = \langle \mathrm{nouns}, \mathrm{verbs}, \mathrm{is the one ...}, \mathrm{towards}, \mathrm{by means of}, \mathrm{does} \rangle$. The examples given on this formal language are then translated to its structure. Statements are determined true or false intuitively depending on what it is referring to in the natural language.
		\item For $\mcL_{C}$, if we use naive set theory, we have $\mathfrak{S} = \langle X^Y, D : X^Y \longrightarrow X^Y, C : X^Y \longrightarrow X^Y, \{ (f,g,h) \mid C(f) = D(g) \land h = f \circ g  \} \rangle$, where $D(f)$ is the identity on the domain of $f$ and $C(f)$ is the identity in the codomain of $f$. This structure intuitively satisfies the axioms given. Then it formally forms a one-sorted category.
		\item For $\mcL_{LM}$ any known left-module suffices. Take, for example, real numbers and the ring $\mathbb{Z}$.
	\end{enumerate}
\end{ejem}
